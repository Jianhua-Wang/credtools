## Recommended Order

If this is your first run:

1. Read [Core Concepts](../getting-started/concepts.md).
2. Run [Quickstart](../getting-started/quickstart.md).
3. Follow [Raw GWAS to Results](from-raw-gwas-to-results.md) with your own files.
4. Use the guide pages when you need to make a choice.

!!! tip "Tutorials use real command names"
    Every tutorial uses the same commands listed in the CLI reference. The
    tutorials explain why you run a step; the reference pages list every flag.
